## 1. 产品愿景与定位

### 1.1 核心价值主张

WealthTrajectory 是一个个人净资产仪表盘，将分散的财务信息整合为统一的、面向未来的视图，让用户不仅能看清今天的财务状况，更能判断自己是否走在实现人生目标的轨道上。

### 1.2 目标用户

| 分层 | 画像 | 核心需求 |
|------|------|---------|
| 核心 | 28-42岁，家庭年收入 $80K-$200K，多类型资产 | 资产整合、退休信心 |
| 次级 | 新购房者、新手父母、职业转型期 | 情景规划 |
| 未来 | 高净值人群 | 辅助诊断工具 |

### 1.3 竞争定位

| 竞品 | 优势 | 我们的缺口 |
|------|------|----------|
| Empower | 免费、全面 | 界面杂乱、过度推销 |
| Kubera | 简洁、手动 | 无预测 |
| Monarch Money | 美观 | 预测弱 |
| 电子表格 | 自定义 | 维护成本高 |

**差异化：** 目标感知的预测 + 用户可控假设 + 简洁界面。

## 2. MVP 范围

### 2.1 范围内（Phase 1）

| 模块 | 功能 | 成功标准 |
|------|------|---------|
| 落地页 | 价值主张、CTA、信任标识、定价 | 转化率 ≥ 8% |
| 认证 | 邮箱 + Google SSO | 流失率 < 2% |
| 资产录入 | 6类资产引导式录入 | 70% 完成完整资料 |
| 仪表盘 | 净资产、配置、趋势 | 加载 < 3秒 |
| 预测 | 1年确定性预测 | 50% 用户7天内查看 |
| 订阅 | 免费版 + Premium付费墙 | 3-5% 付费转化 |

### 2.2 明确不做

- ❌ 实时市场数据
- ❌ Plaid/MX API 集成
- ❌ 税务优化
- ❌ 协作/顾问功能
- ❌ 移动端 App
